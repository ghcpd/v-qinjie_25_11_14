Known Vulnerabilities

1. API Keys Exposed in Responses

Try accessing /api/user-data

2. Secrets in JavaScript

Check browser console after login - secrets are hardcoded

3. Unsafe File Preview (XSS)

POST to /api/preview-file with malicious content

4. Client-Side Data Leakage

Browser console logs contain API keys and credentials

5. Debug Info Endpoint

Visit /api/debug-info for complete system information
